# Synap

> Real-time AI tutor with a live whiteboard. Speak naturally, the AI generates math graphs, 3D simulations, code sandboxes, Manim animations, and diagrams on the fly while it explains.

🌐 **Live demo**: https://synap-five.vercel.app
🏆 Built in 48 hours of the **NMIT Hackathon**

---

## What it does

Synap is a real-time learning companion. You speak (or type), the AI responds in voice, and as it explains it actively populates a shared whiteboard with the right visual for the concept. The AI decides which tool to call — graphing, geometry, animation, code editor, drawing — based on what you're learning.

## ✨ Features (what actually ships)

### Real-time conversation
- **Voice agent** powered by Gemini Live native-audio (`gemini-2.5-flash-native-audio-dialog`) over LiveKit WebRTC. Sub-second latency, natural turn-taking, multilingual.
- **Text chat** alongside voice — the agent reads from the same chat channel.

### Live AI whiteboard — 9 visual modes, all triggered by the agent
| Tool | Use case |
|---|---|
| 📊 **Mermaid** | flowcharts, state machines, ER diagrams |
| 📈 **Desmos** | algebra, calculus, function plotting |
| 📐 **GeoGebra** | geometry, 3D solids, constructions |
| 🎬 **Manim** | 3Blue1Brown-style animated math/CS explanations (Python rendered server-side via Modal) |
| 🌐 **Interactive HTML applets** | three.js, p5.js, Leaflet, Chart.js — generated by Gemini in a sandboxed iframe |
| 💻 **Live code sandbox** | Sandpack-powered React / JS / TS / Vue sandbox the agent populates with full working apps |
| 🎥 **YouTube embed** | when an existing video is the right answer |
| ✏️ **Drawing board** | Tldraw freehand for student sketches |
| 🧪 **Interactive quiz** | MCQ with explanation, agent-generated |

The agent picks the right one — you don't switch tabs.

### Document understanding
- Upload a PDF on `/upload`. `pdf-parse` extracts text, Gemini extracts a list of teachable concepts, all persisted to MongoDB. The concept badges link straight into a session topic.

### Persistence + analytics
- Every session's whiteboard state, messages, and view mode auto-saves to MongoDB Atlas (debounced).
- `/dashboard` shows real recent sessions, message counts, unique topics.
- `/analytics` charts real weekly activity, top topics, and which whiteboard tools have been used most.

### Security
- AI-generated HTML runs in a `sandbox="allow-scripts"` iframe — opaque origin, can't reach session cookies or call same-origin APIs.
- Mermaid runs in `securityLevel: "strict"` mode — no HTML labels, no JS injection from agent-generated diagrams.
- All API routes validate inputs (room IDs, file sizes, state shape) and cap payload sizes.

## 🛠 Tech stack

| Layer | Tech |
|---|---|
| Framework | Next.js 16 (App Router, Turbopack) + React 19 + Tailwind v4 |

## 🚀 Setup

### Prerequisites

- Node 20+
- A Modal account (free tier is plenty for the Manim path)
- Accounts / API keys for: Gemini, LiveKit Cloud, MongoDB Atlas

### 1. Clone + install

```bash
git clone https://github.com/Kundan730/Synap.git
cd Synap
npm install
```

### 2. Environment variables

Create `.env.local` at the repo root:

```bash
# Google Gemini — used for chat, visualizations, transcribe, Manim code-gen, concept extraction
GEMINI_API_KEY=
GEMINI_MODEL=gemini-2.5-flash             # optional override; default flash

# LiveKit Cloud — realtime voice + WebRTC rooms
LIVEKIT_API_KEY=
LIVEKIT_API_SECRET=
NEXT_PUBLIC_LIVEKIT_URL=wss://your-project.livekit.cloud

# MongoDB — session persistence + uploaded document concepts
MONGODB_URI=mongodb+srv://user:pass@cluster.mongodb.net/

# Modal — serverless Manim renderer
MODAL_MANIM_URL=https://<your-username>--synap-manim-render-manim.modal.run
MODAL_MANIM_TOKEN=<a long random string you generate, must match Modal secret>

# Optional — only needed if you wire up alternate paths
ELEVENLABS_API_KEY=
ZOOM_SDK_KEY=
ZOOM_SDK_SECRET=
```

### 3. Deploy the Manim Modal app (one-time)

```bash
pip install modal
modal token new                                 # OAuth login

# Create the shared secret used by /api/manim and the Modal function
TOKEN=$(openssl rand -hex 32)
modal secret create synap-manim MODAL_MANIM_TOKEN=$TOKEN

# Deploy the Python renderer
modal deploy modal/manim_app.py
# Modal will print the public URL — paste it into MODAL_MANIM_URL
echo "MODAL_MANIM_URL=<paste URL here>" >> .env.local
echo "MODAL_MANIM_TOKEN=$TOKEN" >> .env.local
```

The first deploy takes ~3 minutes (LaTeX install). Subsequent deploys are seconds.

### 4. Run

```bash
npm run dev      # starts Next.js + the LiveKit voice agent in parallel
```

Or run them separately:

```bash
npm run dev:next     # Next.js dev server only
npm run dev:agent    # voice agent only (tsx agent.ts dev)
```

Open http://localhost:3000 → click **Start Live Session** → unmute your mic → say *"animate the Pythagorean theorem"* and watch.

## 🧠 How the agent decides what to show

The agent (`agent.ts`) registers a set of LLM tools. When Gemini Live decides a visual is needed, it calls a tool which publishes a `TOOL_CALL` data-channel message. The browser listens via `useDataChannel` and switches the whiteboard view mode. Tools currently exposed:

```
show_mermaid_diagram         → Mermaid renderer
show_desmos_graph            → Desmos
show_geogebra_construction   → GeoGebra
generate_interactive_applet  → Gemini-generated HTML in sandbox iframe
generate_manim_video         → Modal-rendered Manim mp4
play_educational_video       → YouTube
open_drawing_board           → Tldraw
open_code_editor             → Sandpack
show_quiz                    → MCQ renderer
```

Adding a new tool = three places: a new `llm.tool({...})` in `agent.ts`, a new `TOOL_CALL` branch in `useDataChannel` in `src/app/session/page.tsx`, and a renderer component.

## 🗺 Roadmap (what's not built yet)

The platform is intentionally focused on the in-session experience first. Things that are *not yet shipped* and we know about:

- **Authentication / per-user identity** — sessions are currently global. Plug in Clerk / NextAuth + filter Mongo queries by user ID. Search the codebase for `TODO(auth):` to find every spot.
- **Vector search / RAG over uploaded PDFs** — concepts are extracted but you can't currently ask questions *grounded in* the uploaded document. Embedding + retrieval pipeline is the next step.
- **Mastery tracking across sessions** — analytics counts sessions, doesn't yet model per-user concept mastery.
- **Quiz generation from uploaded material** — `/upload` ends at concepts; turning concepts → adaptive quizzes is a 1-day extension.
- **Real-time AI avatar** — explored Simli; the cascading latency on top of Gemini Live made it feel unnatural. Re-introducing it correctly requires switching to a fully cascaded TTS pipeline (text Gemini → ElevenLabs → Simli with shared audio), which trades voice latency for visual presence. Tracked as future work.
- **Curriculum-aware learning roadmaps** — generate personalized journeys (interview prep, exam prep, etc.).
- **Multi-language UI** — Gemini handles the conversation in any language already; UI strings are English-only.
